==============================================================
  MANUAL RÁPIDO DO MATE!_OS  -  para quem vem do Windows
==============================================================

Bem-vindo! O Mate!_OS é um sistema baseado em Linux (Debian)
com a interface MATE. Ele é leve, funciona bem em computadores
mais simples e a maioria das coisas que você faz no Windows
também dá para fazer aqui, só que em outro lugar.


1. A TELA PRINCIPAL
--------------------------------------------------------------
- Área de trabalho: onde ficam os atalhos e o papel de parede.
- Barra inferior (painel): equivalente à barra de tarefas do
  Windows. Mostra os programas abertos, o relógio e a bandeja.
- Ícone no canto inferior esquerdo: abre o MENU de programas,
  o mesmo papel do botão Iniciar do Windows.


2. ABRIR PROGRAMAS
--------------------------------------------------------------
- Clique no ícone do canto inferior esquerdo.
- Digite o nome do programa (por exemplo: "LibreOffice",
  "Code::Blocks", "Arquivos") e pressione Enter.
- Dica: a tecla Windows (Super) também abre o menu.


3. TROCAR ENTRE JANELAS
--------------------------------------------------------------
- Alt + Tab: alterna entre as janelas abertas (igual ao Windows).
- Clique no programa na barra inferior também funciona.


4. ARQUIVOS E PASTAS
--------------------------------------------------------------
- O gerenciador de arquivos se chama "Arquivos" (PCManFM-Qt).
- Ele funciona como o Explorador de Arquivos do Windows.
- Pastas principais:
    Documentos, Downloads, Imagens, Área de trabalho
- Copiar: Ctrl + C    Colar: Ctrl + V    Recortar: Ctrl + X
- Excluir: tecla Delete (vai para a lixeira)
- Renomear: F2
- Atualizar a pasta: F5


5. LIXEIRA
--------------------------------------------------------------
- Arquivos apagados vão para a Lixeira, como no Windows.
- Para recuperar, abra a Lixeira e use "Restaurar".
- Para apagar de vez, use "Esvaziar lixeira".


6. ESCRITÓRIO E PROGRAMAS INCLUÍDOS
--------------------------------------------------------------
- LibreOffice: substitui o Word (texto), o Excel (planilhas)
  e o PowerPoint (apresentações). Os arquivos .docx, .xlsx
  e .pptx abrem normalmente.
- Code::Blocks: ambiente para programar em C e C++.


7. TROCAR O PAPEL DE PAREDE
--------------------------------------------------------------
- Clique com o botão direito na área de trabalho.
- Escolha "Configurações da área de trabalho".
- Selecione uma das imagens da lista.


8. ATALHOS QUE JÁ CONHECE
--------------------------------------------------------------
    Ctrl + C / Ctrl + V   copiar e colar
    Ctrl + Z              desfazer
    Ctrl + S              salvar
    Ctrl + Alt + T        abrir o terminal
    Alt + F4              fechar a janela
    Alt + Tab             trocar de janela


9. DESLIGAR OU REINICIAR
--------------------------------------------------------------
- Abra o menu (canto inferior esquerdo).
- Use a opção de sair/desligar. Ela fica com os botões de
  energia, geralmente no menu ou no botão de sair do MATE.


10. PROBLEMAS COMUNS
--------------------------------------------------------------
- Não consigo abrir um programa: tente pelo menu e, se não
  abrir, reinicie o computador.
- Relógio com horário errado: o fuso do sistema é o de Brasília.
  Se estiver diferente, avise quem administra o computador.
- A tela ficou muito escura ou clara: o tema verde escuro é o
  padrão. Para mudar, procure as configurações de aparência no
  menu.


Dúvidas? Chame quem administra o computador do laboratório.
