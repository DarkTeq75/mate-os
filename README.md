# Mate!_OS

Uma distribuição Linux experimental baseada em Debian, desenvolvida
com foco em educação, informática e reaproveitamento de computadores.

## Objetivos

- Incentivar o uso de software livre.
- Aproveitar computadores antigos.
- Facilitar o acesso a ferramentas de informática.
- Promover a tecnologia verde no ambiente educacional.

## Estrutura do projeto

- `config/`: configuração atual do Debian Live-Build.
- `config-kde-backup/`: backup de uma configuração anterior do KDE.
- `docs/`: página oficial do projeto.
- `gerar_spinner.py`: script auxiliar do projeto.
- `mateos-tema.tar.gz`: arquivo de recursos do tema.
